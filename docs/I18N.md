# Çoklu dil

Kural (CLAUDE.md 15): kullanıcıya görünen hiçbir metin koda yazılmaz.

## Mesajlar

- Temel dil Türkçedir. Her anahtar `packages/shared/src/i18n/messages/tr/<namespace>.ts` içinde tanımlanır; anahtarlar `<namespace>.` ile başlar.
- İngilizce karşılığı aynı PR'da `messages/en/<namespace>.ts` içine eklenir. İngilizce dosya Türkçe dosyanın anahtar tipine bağlıdır; eksik anahtar derleme hatasıdır.
- Yeni ad alanı `messages/index.ts` içindeki `TR_NAMESPACES` ve `EN_NAMESPACES` listelerine eklenir. `i18n.spec.ts` iki listenin aynı anahtarları kapsadığını, hiçbir anahtarın iki dosyada olmadığını, yer tutucuların eşleştiğini ve emoji bulunmadığını denetler.
- Değişkenler `{ad}` yer tutucusuyla, çoğullar `.one` / `.other` anahtarlarıyla yazılır; `t('key', { count })` doğru biçimi `Intl.PluralRules` ile seçer.
- Çeviri değerleri yalnızca düz metin olarak render edilir, asla HTML olarak.

## Ekranlarda

Web sunucu bileşenleri `getT()` (`apps/web/src/lib/i18n.ts`) kullanır; dil sırası: `resget_locale` çerezi, `Accept-Language`, Türkçe. İstemci bileşenleri için `useT()` A2 ile eklenir.

## API

API gövdeleri çeviri taşımaz; makine kodu taşır (`x-error-code`, gövdede `code`). İstemci `errors.<code>` anahtarını çevirir. İzin adları `permissions.<key>`, varsayılan roller `roles.default.<key>`, sipariş durumları `orders.status.<STATUS>`, defter satırları `settlement.line.<TYPE>`.

## Biçimlendirme

Tarih, sayı ve para etkin dile göre `Intl` ile biçimlenir (`formatMoney(money, locale)`). `'tr-TR'` veya `'TRY'` sabit yazılmaz; para birimi restorandan gelir.

## Çevrilmeyenler

Restoran verisi: menü, kategori, masa adı, şube adı, kampanya metinleri. Bunlar restoranın yazdığı gibi gösterilir.

## Diğer diller

Türkçe ve İngilizce kodla gelir. Başka diller dil paketi (JSON veya CSV, `pack.ts`) olarak yüklenir; eksik anahtar Türkçeye düşer.
